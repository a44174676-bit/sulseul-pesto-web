# 구현 및 검증 기록

검증일: 2026-10-18 (대한민국 시간)

## 완료

- React·TypeScript·Vite·Tailwind 프로젝트와 잠금 파일 생성.
- 메인, 브랜드, 제품 2종, 활용법 3종, B2B, 연락처 구현.
- 개인정보 안내 및 미등록 경로 404 화면 구현. 빌드 시 페이지별 HTML 메타데이터 생성.
- 모바일 접기 메뉴, Escape 닫기·포커스 복귀, 본문 건너뛰기, 모션 감소 대응.
- 연락처·제품 별도 데이터, 직접 제작한 교체용 시각 디자인, 개인정보 수집 없는 이메일 문의.
- Netlify 빌드·정적 페이지·404·보안 헤더 설정과 운영 매뉴얼.

## 실제 실행 결과

- Node 24.19.0 / npm 11.9.0.
- `npm ci --cache /workspace/.npm-cache --no-audit --no-fund`: 성공, 잠금 파일 기반 재설치.
- `npm run build`: 성공, TypeScript 검사 포함.
- `npm run test:e2e`: **7개 통과**, 시스템 Chromium 사용.
- 360·768·1440px에서 제품 카드, 연락처, 전체 내비게이션과 메인 버튼 이동, 가로 넘침 없음 확인.
- 모바일 메뉴 열기·닫기·Escape·포커스·키보드 건너뛰기 확인.
- 개인정보, 없는 경로, 404 직접 진입과 홈 복귀 확인.
- axe WCAG 2 A/AA 및 2.1 AA 자동 검사: 위반 0개 (세 화면 크기, 열린 모바일 메뉴, 개인정보·404 화면).
- 빌드된 세 HTML 파일의 페이지별 title·description 확인.
- `npm audit --omit=dev`: 알려진 런타임 의존성 취약점 0개 (검사 시점 기준).

초기 검사에서 작은 안내 문구의 색 대비가 부족해 수정했고, 최종 검사에서는 통과했습니다. 자동 접근성 검사 결과는 전체 WCAG 준수 인증을 의미하지 않습니다.

## 외부 권한 및 미검증 사항

- 기존 GitHub main 초기 README 커밋을 보존하고 그 위에 개발했습니다. 다른 프로젝트는 변경하지 않았습니다.
- GitHub 원격 읽기 성공. `git push --dry-run origin main`은 HTTP 403 권한 거부. 원격 저장 완료로 표시하지 않습니다.
- Netlify 연결·배포 권한이 제공되지 않아 실제 배포 및 배포 URL 없음.
- Netlify에서의 실제 HTTP 404, 보안 헤더 적용 및 소셜 공유 미리보기는 배포 후 확인 필요. Vite preview는 404 상태 검증용 서버가 아닙니다.
- 실제 전화 통화·이메일 발송, iOS/Safari·Android 실기기, 스크린리더 수동 검사는 수행하지 않았습니다.
- 실제 로고·사진, 상세 창업자 이력, 제품 표시정보는 제공되지 않아 임의로 추가하지 않았습니다.
- 문의폼·가격·재고·결제·회원가입은 범위에서 제외했습니다.
- 정식 공개는 창업자 승인 및 개인정보 처리조건 확인 후 진행해야 합니다. 현재 robots/noindex로 검색 수집 차단 중이며, 접근 제한 기능은 아닙니다.
